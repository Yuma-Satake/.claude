# tool-open-vscode

変更内容が置かれているディレクトリをVSCodeで開き、ユーザーが自分の目で変更内容(diff)を確認できるようにする。

## 対象ディレクトリ

対象ディレクトリ: !`pwd`

このディレクトリは呼び出し時点（フォーク前）の実際の作業ディレクトリであり、worktreeやサブディレクトリで作業していた場合もそのパスを正しく指している。`context: fork`実行のため会話履歴は参照できないが、このディレクトリを対象にすれば十分であり、他の場所を推測しない。

## 実行手順

1. 上記の対象ディレクトリに対して以下を実行する。

```bash
code <対象ディレクトリ>
```

2. `code` コマンドが見つからない(`command not found`)場合は、以下にフォールバックする。

```bash
open -a "Visual Studio Code" <対象ディレクトリ>
```

3. 実行結果を下記フォーマットで報告する。

## 出力フォーマット

このスキルの成果物はVSCodeを開くという副作用そのものであり、テキストは成果物ではない。最終報告は下記の英語固定パターン1行のみとする。これはグローバル言語ルール（常に日本語で応答する）に対する明示的な例外である。分岐ごとに以下のいずれかを一字一句そのまま使い、他のプロースに言い換えない。`<dir>`は対象ディレクトリの絶対パスに置き換える。

- `vscode: opened <dir>` — 開けた場合
- `vscode: failed (command not found)` — `code`・`open -a`のいずれも失敗した場合

## 注意点

- ディレクトリを開くだけで十分。特定のファイルやビューを指定して開く必要がある場合(diffビューの直接指定など)は、このスキルの範囲外なので都度対応する。
- `code` コマンドの有無は環境によって異なるため、フォールバックを省略しない。
