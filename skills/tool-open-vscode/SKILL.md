# tool-open-vscode

変更内容が置かれているディレクトリをVSCodeで開き、ユーザーが自分の目で変更内容(diff)を確認できるようにする。

## 実行手順

1. 変更内容が置かれているディレクトリを対象に以下を実行する。通常は現在の作業ディレクトリだが、別のworktreeやサブディレクトリで作業していた場合はそのパスを明示的に指定する。

```bash
code <変更内容のあるディレクトリ>
```

2. `code` コマンドが見つからない(`command not found`)場合は、以下にフォールバックする。

```bash
open -a "Visual Studio Code" <変更内容のあるディレクトリ>
```

3. 実行結果を下記フォーマットで報告する。

## 出力フォーマット

このスキルの成果物はVSCodeを開くという副作用そのものであり、テキストは成果物ではない。最終報告は下記の英語固定パターン1行のみとする。これはグローバル言語ルール（常に日本語で応答する）に対する明示的な例外である。分岐ごとに以下のいずれかを一字一句そのまま使い、他のプロースに言い換えない。`<dir>`は開いたディレクトリの絶対パスに置き換える。

- `vscode: opened <dir>` — cwdと同じディレクトリを開けた場合
- `vscode: opened <dir> (not cwd)` — cwdと異なるディレクトリを開いた場合（worktreeなど。差分が見えない事故を防ぐため、cwdと異なることを必ず明示する）
- `vscode: failed (command not found)` — `code`・`open -a`のいずれも失敗した場合

## 注意点

- ディレクトリを開くだけで十分。特定のファイルやビューを指定して開く必要がある場合(diffビューの直接指定など)は、このスキルの範囲外なので都度対応する。
- `code` コマンドの有無は環境によって異なるため、フォールバックを省略しない。
- このスキルの目的は「ユーザーに差分を見せること」であり、「cwdを開くこと」ではない。worktree内で作業していた場合にメインのチェックアウトを開くと、ユーザーには差分が一切見えない。
