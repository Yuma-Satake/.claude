対象リポジトリの解決からHunkペインの起動・リロード・再起動までを1本のスクリプトで行う。判定ロジック・除外理由・リトライ仕様はスクリプト内コメントを参照する（ここには書かない）。

## 実行

1. 現在のタスクで編集・作成・削除したファイルパスが分かる場合、各パスを`--changed-file <path>`で渡す（複数指定可）。これが最優先の情報源であり、カレントディレクトリや別worktreeを優先してはならない。
2. 変更ファイルが不明で作業worktreeだけが明示されている場合は`--worktree <path>`を渡す。どちらも不明なら両方省略する（現在または兄弟worktreeから自動解決する）。
3. 対象リポジトリの作業ツリーがcleanで、かつこのタスク中に対象リポジトリへ複数コミットしたと会話内の記録から確認できる場合、タスク開始時点のHEAD（最初のコミット直前）を`--task-start-ref <ref>`で渡す。1コミットのみ、または不明なら省略する。

```bash
bash ~/.claude/skills/hunk-open/scripts/hunk_open.sh [--changed-file <path> ...] [--worktree <path>] [--task-start-ref <ref>]
```

4. 標準出力の最後の1行をそのままユーザーに報告する。これはグローバル言語ルール（常に日本語で応答する）に対する明示的な例外であり、再要約・再翻訳しない。
