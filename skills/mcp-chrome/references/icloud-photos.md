# iCloud 写真（icloud.com/photos）

共有アルバムの中身（ファイル名の一覧）を調べるときの知見。

## ファイル名の取得

- ウェブ版の一覧・詳細にはファイル名が表示されない。画像の見た目と枚数しか分からない
- 全選択（アルバムのグリッドをクリックしてから Cmd+A）し、右上のダウンロードのアイコンから「N項目をダウンロード」を選ぶと、元のファイル名の zip が得られる。ファイル名だけが必要なら、zip は展開せず `unzip -Z1` で一覧を出す
- 同じメニューの「N項目をライブラリに保存」は、写真ライブラリに複製を作るため使わない
- zip は全項目の元データを含むため大きい（数GB になることがある）。ダウンロード前に、保存先の空き容量とサイズの目安をユーザに伝える
- zip の中のファイル名は、元の名前から変わらない。ローカル側で記号などを足して改名している素材は、記号を除いた名前で照合する

## 使えなかった方法

- 共有リンクのトークンから `p<番号>-sharedstreams.icloud.com/<トークン>/sharedstreams/webstream` を推定して取得する方法は、404 になった
- ログイン済みのウェブ版が使う `sharedstreams/getchanges` はリクエスト本文が不明で、ネットワークログからは本文を読めない
- Mac の写真ライブラリ（osxphotos）は、共有アルバムの同期が無効だと中身が空になる

## ダウンロードの完了待ち

- ダウンロード中は `.crdownload` が出る。ダウンロードフォルダの `.crdownload` が消えるまでを、Monitor の until ループで待つ（一定間隔で毎回出力すると通知が増えすぎる）
