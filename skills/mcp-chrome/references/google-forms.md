# Google Forms 操作ナレッジ

Google フォーム（docs.google.com/forms）で、Chrome MCP からフォームを作成・編集する場合の固有ナレッジ。

## フォーム作成時のデフォルト設定

ユーザーから特に指定がない場合、フォームを作成・整備する際は以下を既定として設定する。指定と食い違う場合はユーザーの指定を優先する。

- メールアドレスの収集: 「回答者が入力（Responder input）」にする
  - 「確認済み（Verified）」は回答にGoogleログインが必須になり、Googleアカウントを持たない人が回答できなくなる
- 回答のコピーを回答者に送信: 「常に（Always）」にする。メールアドレスの収集がオフだと選べないため、先に収集を設定する
- 新しい回答のメール通知: 「回答」タブ右上の「︙」から「新しい回答についてのメール通知を受け取る」をオンにする（フォームのオーナー宛てに届く）
- 氏名を尋ねる質問: 説明文に「姓と名の間に全角スペースを入れてご記入ください。例：佐竹　友真」のように、全角スペース区切りの書式と例を記載する
- 説明文に書くURL: プレーンテキストのままにせず、リンク化する（手順は後述）

## 操作上の注意点

### タブが非表示状態だと描画が遅れる

ブラウザのウィンドウが背面・最小化されているなど、`document.visibilityState` が `hidden` の状態では、メニューの開閉やレイアウト変更のアニメーションが大きく遅れる。スクリーンショットが実際のDOMより古い状態を映し、直前のスクリーンショットの座標でクリックすると別の要素を押してしまう。

- 操作ごとに2〜4秒待ってからスクリーンショットを撮り直し、最新の位置を確認してからクリックする
- 設定値の反映確認はスクリーンショットではなく、`javascript_tool` でDOM（`aria-label` や入力値）を直接読んで行う。ただしプルダウンの `aria-selected` も描画に追随して遅れることがあるため、最終確認は公開フォームのデータで行う（後述）

### 入力欄をクリックすると全文が選択される

質問タイトル・説明文・セクション説明などの入力欄は、クリックでフォーカスした時点で既存の全文が選択状態になることがある。そのまま文字を入力すると全文が上書きされる。

- 追記したい場合も、全文を打ち直す前提で `cmd+a` → 全文を入力し直す
- 入力後は `document.activeElement.innerText` で内容を確認する

### 選択肢の書き換えはクリックで行う

`javascript_tool` で選択肢の input に `focus()`/`select()` してから `type` すると、入力が確定されず「Option 6」のような仮の選択肢名がそのまま保存されることがある（公開中のフォームにも即座に反映される）。

- 選択肢の書き換えは、編集状態の質問カード内で対象の選択肢を実際にクリック → `cmd+a` → `type` で行う
- 書き換えた後は必ず選択肢の一覧を読み直し、`Option N` が残っていないか確認する

### 説明文のURLをリンク化する

1. 説明文の欄をクリックしてフォーカスする
2. `javascript_tool` で、フォーカス中の要素内のURLのテキストだけを `Range` で選択する
3. `cmd+k` で「Add Link」ダイアログを開き、「Link to」にURLを入力する
4. OKボタンは座標ではなく `find` で ref を取得してクリックする（座標クリックは描画遅れで外れやすい）
5. 説明欄の `innerHTML` に `<a href=...>` が入ったことを確認してから、欄外をクリックして保存する

### ヘッダー画像のアップロード

テーマの「Choose Image」→「Upload」の画像選択画面は別オリジンのiframeで、`file_upload` で使う file input を取得できない。

- 画像をローカルの簡易HTTPサーバー経由でブラウザのタブに表示し、`computer` の screenshot を撮る
- その screenshot ID を `upload_image` の `coordinate` 指定でUploadのドロップ領域へドラッグ＆ドロップする
- 画像は画面中央に配置しておくと、続く切り抜き画面の既定の選択範囲にそのまま収まる
- アップロードされる解像度はスクリーンショットのサイズ（ビューポート幅）に依存する

### 公開フォームのデータで最終確認する

編集画面の表示は描画遅れの影響を受けるため、最終的な確認は公開フォーム（`/viewform`）のHTMLを `curl` で取得し、埋め込まれた `FB_PUBLIC_LOAD_DATA_` のJSONから質問・説明・選択肢・必須設定を読んで行う。説明文のリンクはこのJSON内のHTML版（`<a href...`）で確認できる。

### 回答画面での確認は下書きに注意する

ユーザーと同じアカウントで公開フォームを開くと、ユーザーがテストで入力した下書きが復元される。表示確認のために選択肢を操作した場合は元に戻し、送信は行わない。
