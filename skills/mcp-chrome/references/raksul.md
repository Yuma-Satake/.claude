# ラクスル (raksul.com)

はがき・ポストカード印刷の料金確認、データ入稿、データチェックまでを操作した際の知見（2026-10時点）。

## URL

- はがきの入口は `https://raksul.com/print/postcard/`。`/postcards`、`/postcard/` は「ページが見つかりませんでした」になるか、リダイレクトされる
- 通常サイズはがきの料金表は、条件をクエリで指定できる。ページ読み込み後に、用紙と部数を直接URLで切り替えるのが速い

```
https://raksul.com/print/postcard/prices?kind=KIND_POSTCARD&size=POSTCARD&paper={用紙}&weight=180&color=BOTH_SIDE_COLOR&amount={部数}&business_day={出荷日数}&folding=FOLDING_NONE&rounded=ROUNDED_NONE
```

| パラメータ | 値 |
|---|---|
| paper | `WOODFREE`（普通紙・上質）、`WHITE_KENT`（ケント）。光沢紙・マット紙などは、用紙モーダルで選ぶとURLに反映されるので、そこから取得する |
| weight | `180`（標準）。厚手は220 |
| color | `BOTH_SIDE_COLOR`（両面カラー） |
| amount | 部数（10部が最小） |
| business_day | `1`、`3`、`5`（出荷までの営業日） |

## 料金表の操作

- 料金表は、読み込み中は灰色のスケルトン表示になる。`wait` を3秒挟んでから `zoom` で読み取る
- 用紙の変更は、「用紙 / 厚さ」の欄を押すとモーダルが開く。座標クリックでは開かないことがあり、`read_page(filter="interactive")` で取った `ref` のボタンを `left_click` すると開いた
- モーダルの中の用紙ごとのラジオボタンは、座標クリックで選べる。モーダル内は縦に長いので、モーダル上で `scroll` して、ケントなどを探す。「選択する」を押すとURLの `paper` が変わる
- 「選択する」の直後は、モーダルが残ったまま料金が更新される。数秒待って、`zoom` で料金表を読む
- 料金表の列（1営業日、3営業日、5営業日）のセルを押すと、その出荷日数が選ばれ、画面下の合計が更新される。「カートに追加する」でカートへ進む
- 料金表の値は、税抜が大きく、税込が小さく表示される。税込のほうを使う

## 料金の目安（10部、両面カラー、送料込み、税込、2026-10時点）

| 用紙 | 1営業日 | 3営業日 | 5営業日 |
|---|---|---|---|
| 光沢紙（アートポスト） | 1,892円 | 1,607円 | 997円 |
| 普通紙（上質）180kg | 1,893円 | 1,852円 | 1,534円 |
| ケント180kg | 3,116円 | 2,509円 | 2,196円 |

ケントは、40部で5営業日出荷が2,575円。件数（データの種類）を増やすと、その分だけ料金が増える。

## データ入稿

- カートの「データを入稿する」を押すと、データ入稿のページになる。ファイルのアップロードは、`find` で「ファイルから選択」のファイル入力の `ref` を取得し、`file_upload` で行う
- `file_upload` は、セッションが読めるフォルダ内のファイルしか受け付けない。作業ディレクトリの外のファイルは「only files this session is allowed to read」で失敗する。作業ディレクトリを変えるか、`/add-dir` でフォルダを追加してもらう。許可の回避（別の場所へコピーなど）はしない
- 表面と裏面は、2つのPDFを1回の `file_upload` で同時にアップロードできる
- アップロード後に「データチェックを行う」を押すと、処理に20〜30秒かかる。完了すると結果ページ（`/datacheck/result`）になる
- 結果ページの「注意事項 N件」「自動修正 N件」は、`find` で取った `ref` の `left_click` か、座標クリックでダイアログが開く。`get_page_text` には、ダイアログの内容は出ない
  - 「塗りつぶし部分に色味の薄い部分があるため、仕上がりにうまく反映されないことがあります」は、淡い背景色で出る
  - 「透明効果がある部分を埋め込みました」は、ラクスルがPDFの透明を自動処理した通知
- 「確認用PDFで確認する」を押すと、PDFが `~/Downloads` にダウンロードされる。ダウンロードにあたるので、押す前にユーザーの許可が必要。PDFは3ページで、1ページ目は説明、2ページ目以降が表面・裏面のプレビュー（斜めに「Sample」の透かしが入る）
- 「最終確認へ進む」を押すと、「仕上がりプレビューをご確認ください」のモーダルが出る。「データに問題が無い事を確認の上　データを入稿する」を押すと、お届け先・支払いの設定に進む。このボタンはデータの確認の宣言になるので、ユーザーの許可を取るか、ユーザー自身に押してもらう
- データの差し替えは、カート（`/print/purchase/cart`）の「データを変更する」を押す。アップロード済みのデータは空になるので、表面・裏面の両方をあらためてアップロードし、データチェックからやり直す。「データを削除する」と並んでいるので、押し間違えない

## お届け先・支払い・注文確定

- カートの「支払い、お届け先の入力へ」を押すと、お届け先の設定（`/print/purchase/delivery`）になる。「お届け先を追加/変更する」は、ref のクリックで反応しないことがあり、座標クリックで開く
- アカウントに保存済みの住所は、モーダルの一覧からチェックボックスを選び、「選択する」を押す。複数ある場合は、どれを使うかをユーザーに確認する
- 領収書の郵送は、初期値が「不要」（必要は330円）。部数の欄は、住所の選択後に10部などが入る
- 「支払い方法を選択する」を押すと、支払い画面（`pay.raksul.com`）になる。一度で進まないことがあるので、遷移していなければ、もう一度押す
- 支払い画面には、登録済みのクレジットカードの下4桁、クーポン、ポイント、注文商品一覧（データ名を含む）が出る。使用データ名が、意図したファイルか確認する
- 注文の確定ボタンは、画面上は「注文する」。`find` で「注文を確定する」と検索すると、この ref が見つかる。確定後は、変更もキャンセルもできないので、内容を提示してユーザーの確認を取ってから押す
- 完了すると、「お支払い完了」のページに注文番号（12桁）が出る。ラクスルが数分以内にデータの最終確認を行い、問題がなければ受付日が確定する

## 確認用PDFの読み取り

- `Read` ツールでPDFを読むには `pdftoppm`（poppler）が必要で、入っていないと失敗する。ツールは勝手に入れず、macOS標準の `PDFKit` を使うSwiftの小さなスクリプトで、ページを `thumbnail` にして PNG に書き出すと読める
- `sips -s format png` は、1ページ目しか画像にできない
- 色を比べる場合は、同じ描画方法のファイル同士でサンプルする。CMYKのPDFは、この描画方法では暗めのRGBに見える。ラクスルの画面上のプレビューのほうが、デザインに近い色で表示される

## 入稿データの仕様（はがき、通常サイズ 100×148mm）

- 最小注文は10部。ご注文件数（データの種類）は1〜20
- 塗り足しは3mm（入稿用紙は106×154mm）。トンボなしでも、塗り足し込みのPDFは受け付けられる
- PDFが推奨。RGBのデータは、ラクスルがCMYKに自動変換する。色味が変わる可能性がある
- 印刷方式（オフセット、デジタル、オンデマンド）は指定できない
- 用紙のうち、光沢紙（アートポスト）はコートがあり、インクジェットのインクが乗りにくい可能性がある。コートなしの普通紙（上質）、ケントは、乗りやすいと考えられる（実物で未確認）
