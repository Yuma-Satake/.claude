# パッケージ管理規約

- 依存関係の変更は直接 `package.json` や `package-lock.json`/`yarn.lock` を直接編集することを禁止する。必ずパッケージマネージャのコマンドを使用して行うこと
- 対象のパッケージ管理方式にコマンドラインでの追加・削除手段が存在しない場合（例: XcodeプロジェクトのSwift Package Manager統合は`.xcodeproj`ファイルを介し、Xcode GUI操作以外にCLIでの追加手段がない）、設定ファイルの直接編集を上記禁止の例外として許容する。ただし編集後は依存解決ツール（例: `xcodebuild -resolvePackageDependencies`）や実際のビルドで構造的整合性を必ず検証すること
- 新しいパッケージを導入する際には、既存の依存関係を変更することなく導入できる最新バージョンを導入すること
- パッケージのバージョン指定の際には、可能な限り詳細なバージョン（例: `1.2.3`）を指定し、範囲指定についてはキャレットを使用すること
- 依存関係の追加/削除/更新を行う際には、それを参照しているドキュメントやコメントがないか、コードベースを探し、必要に応じて更新すること
